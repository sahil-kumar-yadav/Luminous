
# 🌟 Luminous Web – Voice-First Accessible Platform

**Luminous Web** is an accessible, speech-first web application designed for visually impaired users or anyone who prefers voice interaction. With full voice navigation, music playback, and text-to-speech books, users can control the entire website without touching the keyboard or mouse.

---

## **Features**

### 🎵 Music Player

* Play, pause, skip, or go back to previous songs using voice commands.
* Supports playlists and auto-advance.
* Accessible audio controls with keyboard and voice-first interactions.

### 📚 Accessible Books

* Text-to-speech for books and documents.
* Voice commands like: “Read book X”, “Next chapter”, or “Stop reading”.
* Adjustable TTS voices, speed, and pitch for comfortable listening.
* Bookmark and resume reading anywhere.

### 🗣️ Voice Command Navigation

* Navigate the entire site via voice: “Go to Music”, “Open Books”, “Show Settings”.
* Global voice commands for key actions like dark mode toggle or font resizing.
* Phrases detection with adjustable confidence for higher accuracy.

### 📝 Voice Notes & Dictation

* Record quick notes using speech.
* Manage notes via voice commands: “Show my notes”, “Delete last note”, “Search note about X”.

### 🌈 Accessibility Enhancements

* High-contrast and dark mode support.
* Focus highlighting and skip links for faster navigation.
* Keyboard-first design combined with voice-first interactions.

### 🌐 Multi-Language Support

* Commands and TTS can be extended to multiple languages.
* Users can switch languages dynamically while interacting with content.

## **Installation**

1. Clone the repository:

```bash
git clone https://github.com/yourusername/luminous-web.git
cd luminous-web
```

2. Install dependencies:

```bash
npm install
```

3. Run the development server:

```bash
npm run dev
```

4. Open your browser at `http://localhost:3000`.

---

## **Usage**

* Use voice commands to navigate and control music/books.
* Start listening: Click the **🎙 Start Listening** button.
* Stop listening: Click the **⏹ Stop** button.

### Example Commands:

* Music: “Play”, “Pause”, “Next”, “Previous”
* Books: “Read book X”, “Next chapter”, “Stop reading”
* Navigation: “Go to Music”, “Open Books”, “Toggle Dark Mode”

---

## **Technologies Used**

* **React 18 + Next.js 13** – Client-side and server-side rendering.
* **Web Speech API** – For speech recognition and TTS.
* **Tailwind CSS** – Rapid UI development and responsive design.
* **Accessibility First** – Focus management, skip links, and ARIA roles.
